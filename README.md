# 📊 SAP Tax & Operations Analytics (Power BI)

A governed **Power BI** reporting solution for SAP-based **Tax & Operations** reporting,built as a portfolio project using **sample / masked data only**. It reflects the approach I used in real reporting-modernization work — turning fragmented, multi-source reporting
into a governed Power BI dataset with shared KPI definitions.

## ✨ What this project shows
- **Governed data model** with standardized KPI definitions and a KPI glossary
- **DAX measures** and **Power Query / M** transformations
- Designed for **incremental refresh** and near real-time updates
- **Anomaly-detection prototype** for spotting irregularities in operational data
  (STL decomposition + rolling z-score)

## 🛠️ Built With
Power BI · DAX · Power Query (M) · Python
